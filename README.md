# 숨쉬는길 (soomgil)

대전형 대기 위험 회피 내비게이션. 공공데이터로 대전의 꽃가루·미세먼지·폭염·오존을
실시간 분석하고, 풍향과 분지 지형의 대기정체까지 반영해 **상대적으로 안전한 이동 경로**를
안내합니다.

고등학생 창업 프로토타입 · 공모전 출품작

---

## 시작하기

```bash
npm install
npm run dev
```

http://localhost:3000

지금은 **예시 데이터(mock)** 로 동작합니다. 인증키 없이 모든 화면이 완전하게 돌아갑니다.

### 계절 보기 전환

헤더 아래 **계절 보기** 토글에서 봄·여름·가을·겨울을 눌러 바꿀 수 있습니다.
선택은 URL 쿼리(`?season=`)에 남으므로 특정 계절 화면을 그대로 링크로 공유할 수 있습니다.

| 계절 | 주소 | 상황 |
|---|---|---|
| 봄 | `/?season=spring` | 참나무 꽃가루 매우높음 + 황사 유입 |
| 여름 | `/?season=summer` | 폭염경보 + 오존 나쁨 |
| 가을 | `/?season=autumn` | 잡초 꽃가루 + 미세먼지 |
| 겨울 | `/?season=winter` | 초미세먼지 매우나쁨 + 한파 |

아무것도 붙이지 않으면 **오늘 날짜에 해당하는 계절**로 동작합니다.

실데이터 모드에서도 토글은 그대로 쓸 수 있습니다. 다만 기상청·에어코리아가 주는 값은
**오늘** 것뿐이라, 오늘이 아닌 계절을 고르면 그 계절의 예시 시나리오로 채우고
토글 막대에 **"예시 데이터" 배지**를 띄웁니다. 실데이터(오늘 계절)와 예시 데이터를
화면에서 구분할 수 있게 하기 위한 장치입니다.

### 화면 크기 조절 (어르신 접근성)

헤더의 **가 / 가 / 가** 버튼으로 기본·크게(1.15배)·아주 크게(1.35배)를 고릅니다.
좁은 화면에서는 전체 메뉴 맨 위에 있습니다.

동작 방식은 CSS 한 줄입니다 — `<html data-ui-scale>` 에 맞춰 루트 글자 크기를 키웁니다.
이 저장소의 글자 크기는 전부 `rem` 이고 Tailwind 의 간격·높이 유틸리티도 `rem` 이라,
**글자와 터치 영역이 함께** 커집니다. 둘 중 하나만 커지면 글씨는 큰데 버튼은 그대로라
오히려 누르기 어려워집니다.

> 새 컴포넌트를 만들 때 `text-[13px]` 대신 `text-[0.8125rem]`(=13÷16) 을 쓰세요.
> px 로 적으면 그 글자만 배율을 따라오지 않습니다.

요금제 제한을 두지 않습니다. 이유는 `src/lib/a11y/uiScale.ts` 주석에 적어 두었습니다.

## 수익 모델

공모전 심사에서 "이렇게 돈을 번다"를 보여주기 위한 부분입니다.
**실제 제휴 계정과 광고 네트워크는 아직 연결하지 않았습니다** (사업자·성인 명의 필요).

| 구성 | 지금 | 나중에 바꿀 곳 |
|---|---|---|
| 계절 맞춤 상품 추천 | 네이버쇼핑 검색 링크 | `components/commerce/ProductCard.tsx` 의 `buildShoppingUrl()` **한 함수만** |
| 배너 광고 자리 | 계절별 샘플 문구 플레이스홀더 | `components/ads/AdSlot.tsx` 의 배너 마크업만 |
| 구독 (4단계) | 체험 전환 (결제 없음) | `lib/subscription/usePlan.ts` 의 저장소를 서버 구독 조회로 |

### 요금제 4단계

| | 무료 | 라이트 | 프리미엄 | 패밀리 |
|---|---|---|---|---|
| 월 | 0원 | 1,500원 | 2,900원 | 4,900원 |
| 배너 광고 | 표시 | 제거 | 제거 | 제거 |
| 경로 비교 | 추천 1개 | 추천 1개 | 3안 + 구간별 기여도 | 3안 + 구간별 기여도 |
| 즐겨찾기·알림 | 1곳 | 1곳 | 여러 곳 + 알림 | 여러 곳 + 알림 |
| 가족 계정 | — | — | — | 최대 4인 |

금액은 예시입니다. 화면 게이팅은 요금제 이름이 아니라 `PlanCapabilities`(`config/plans.ts`)만
봅니다 — 요금제가 늘어나도 게이팅 코드는 그대로입니다.

```ts
const { ads, routeCompare, favorites, alerts, familySeats } = usePlanCapabilities();
```


상품 목록은 `config/products.ts` 에 계절별로 정의돼 있고, 이번 계절의 핵심 위험
지표(`config/seasons.ts`)와 연결됩니다. 계절이 바뀌면 추천 상품과 광고 문구가
자동으로 함께 바뀝니다.

- 일반의약품은 온라인 판매가 제한되므로 "구매하기" 대신 **"제품 정보 보기"** 로 표시하고
  약사 상담 안내를 함께 노출합니다.
- 광고 자리에는 **"광고" 표시를 항상 유지**합니다 (표시광고법 + 공공서비스 신뢰).
- 제휴 링크로 바꿀 때는 대가성 표시 문구를 `SeasonProducts.tsx` 하단에 추가해야 합니다.

## 실제 공공데이터로 전환하기

코드는 손대지 않습니다. `.env.local` 두 줄만 채우면 됩니다.

```bash
cp .env.example .env.local
```

```env
NEXT_PUBLIC_DATA_MODE=live
DATA_GO_KR_SERVICE_KEY=<공공데이터포털 일반 인증키(Decoding)>
```

키가 비어 있으면 `live`로 설정해도 자동으로 mock으로 떨어집니다. 시연 중 사고를 막기
위한 장치입니다. 실 API 호출이 실패해도 예시 데이터로 대체하고 콘솔에 경고를 남깁니다.

### 신청할 API 4종 (data.go.kr)

| 서비스 | 쓰는 곳 |
|---|---|
| 기상청_꽃가루농도위험지수 조회서비스 | 소나무·참나무(3~6월), 잡초류(8~10월) |
| 기상청_생활기상지수 조회서비스 (3.0) | 대기정체지수 |
| 기상청_단기예보 조회서비스 | 기온·습도·풍속·풍향 (체감온도 산출용) |
| 한국환경공단_에어코리아_대기오염정보 | 미세먼지·초미세먼지·오존 |

전환 전 확인할 항목은 코드 안에 `TODO(live)` 로 표시해 두었습니다.

```bash
grep -rn "TODO(live)" src/
```

주요 항목:
- `src/lib/api/endpoints.ts` — 오퍼레이션명을 기술문서와 대조
- `src/data/districts.ts` — `areaNo`·예보 격자 대조 (인접 구가 같은 격자를 공유하는 건 정상)
- `src/data/stations.ts` — 에어코리아 측정소가 현재도 운영 중인지 확인

### TMAP 보행자 경로 API (선택)

경로 안내를 **실제 도로 기반**으로 바꾸려면 TMAP 앱키가 필요합니다. 공공데이터포털과는
다른 사업자(SK Open API)라 별도로 발급받습니다.

1. [tmapapi.tmapmobility.com](https://tmapapi.tmapmobility.com) 회원가입
2. 앱 등록 → 앱키 복사
3. `.env.local` 에 추가

```env
TMAP_APP_KEY=<발급받은 앱키>
```

`NEXT_PUBLIC_` 을 붙이지 마세요. 브라우저에 노출되면 다른 사이트에서 남용해
호출 한도를 소진시킬 수 있습니다.

키가 없거나 호출이 실패하면 **격자 A* 근사 경로로 자동 전환**됩니다. 코드 수정은
필요 없고, 화면 상단에 지금 어느 엔진으로 계산된 경로인지 항상 표시됩니다.

### 가로수길 데이터 (선택)

봄철 소나무·참나무 꽃가루 노출을 경로 구간별로 보정하는 데 씁니다.
지금은 예시 데이터로 동작하며(`src/data/street-trees.ts`), 실제 데이터로 바꾸는 절차는
아래와 같습니다.

1. [전국가로수길정보표준데이터](https://www.data.go.kr/data/15021145/standard.do) 접속
2. **파일데이터 → 다운로드** (CSV/JSON) — 오픈API와 달리 활용신청 승인 대기가 없습니다
3. 대전 지역만 필터링하고, `가로수종류` 가 소나무·참나무인 행만 남깁니다
4. `src/data/street-trees.ts` 의 `loadStreetTrees()` 가 그 파일을 읽도록 바꿉니다

표준데이터 컬럼이 이미 우리 타입과 1:1로 대응합니다.

| 표준데이터 컬럼 | 우리 필드 |
|---|---|
| 가로수길명 | `name` |
| 가로수길시작위도 / 시작경도 | `start` |
| 가로수길종료위도 / 종료경도 | `end` |
| 가로수종류 | `species` |
| 가로수수량 | `count` |
| 도로명 | `road` |

`loadStreetTrees()` 만 바꾸면 되고 `lib/risk/tree-proximity.ts` 는 손대지 않습니다.
데이터는 매월 초 전국 단위로 병합되므로, 파일을 받아 저장소에 넣어 두는 편이
매 요청 API를 부르는 것보다 빠르고 안정적입니다.

## 배포 (Vercel)

1. GitHub에 저장소를 만들고 푸시
2. [vercel.com](https://vercel.com) → New Project → 저장소 선택
3. 프레임워크는 Next.js로 자동 인식됩니다. 빌드 설정을 바꿀 필요 없습니다.
4. 환경변수는 실 데이터로 전환할 때만 넣습니다
   (`NEXT_PUBLIC_DATA_MODE`, `DATA_GO_KR_SERVICE_KEY`)
5. Deploy

`.env.local` 은 git에 올라가지 않습니다. **인증키를 커밋하지 마세요.**

배포 후 `src/config/site.ts` 의 `SITE.url` 을 실제 주소로 바꾸면 메타태그·사이트맵에
반영됩니다.

## 계산 방식

```
지표 원단위값
  → ① 0~100 정규화 (4단계 경계값이 25/50/75에 오도록)
  → ② 계절 가중합            = 보정 전 점수
  → ③ 대기정체 보정 (최대 ×1.35)
  → ④ 0~100 클램프           = 최종 점수
```

②③④를 모두 남겨 화면에서 "대기정체로 +24.9% 상승"을 그대로 보여줍니다.

경로 안내는 여기에 **풍향 보정**(바람 불어오는 쪽이 더 나쁘면 가산)과
**하천축 보정**(갑천·유등천·대전천 주변은 확산이 좋아 감산)을 더합니다.

경로 자체는 두 가지 엔진 중 하나로 만듭니다.

| 엔진 | 조건 | 방식 |
|---|---|---|
| `tmap` | `TMAP_APP_KEY` 있음 | TMAP 보행자 경로 API로 실제 도로 폴리라인을 받아, 100m 간격 샘플링 + point-in-polygon으로 통과 행정동을 판정 |
| `grid` | 키 없음 / 호출 실패 | 대전 전역 약 550m 격자 위 A* 근사 경로 |

**위험도 계산은 두 엔진에서 완전히 동일합니다.** 경로 좌표만 다를 뿐
정규화·보정·노출량 계산은 같은 코드를 통과합니다.

### 턴바이턴 안내

TMAP 응답에는 좌표 말고도 회전정보(`turnType`)·구간설명(`description`)·도로명이 들어 있어,
경로 화면의 **길 안내** 탭에 단계별로 펼칩니다 (`lib/routing/tmap.ts` 의 `parseGuides`).

응답이 항상 `[Point, LineString, Point, …]` 로 번갈아 오지는 않습니다. 회전 없이 도로명만
바뀌는 곳에서는 `Point` 없이 `LineString` 이 연달아 옵니다. 이걸 앞 안내에 합치면 화면의
거리가 안내 문구의 거리와 어긋나므로, 별도의 "계속 직진" 단계로 세웁니다. 그래야 각 단계의
거리가 문구와 일치하고 단계 거리의 합이 총 거리와 맞습니다.

격자 근사 경로에는 실제 도로가 없어 안내를 만들지 않습니다 — 없는 안내를 지어내면
그대로 걸을 수 없습니다.

TMAP은 대안 경로를 여러 개 주지 않으므로, 출발-도착 직선의 중점에서 좌우로 벌린
경유지 후보를 만들고 위험도 지도로 미리 걸러낸 뒤 상위 2개만 추가로 호출합니다
(요청당 TMAP 호출 3회).

자세한 내용과 한계는 서비스의 [이용안내](/guide) 페이지에 정리돼 있습니다.
